Plane GCal Sync

A personal utility that mirrors Plane project tasks into Google Calendar.

Plane GCal Sync is a small script run by one person on their own computer. It reads tasks with due dates from a private Plane workspace and creates matching events in that same person's Google Calendar. It is not a product or a service, and has exactly one user: its author.

The app requests a single Google permission — access to the user's own Google Calendar — which it needs in order to create and update the events it manages. It requests nothing else.
