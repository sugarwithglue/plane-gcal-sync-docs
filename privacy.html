Privacy Policy

Plane GCal Sync · Last updated 12 October 2026

Summary

Plane GCal Sync is a personal script with a single user. It runs locally on that user's own computer, talks only to Plane and to Google Calendar, and sends data to no one else. There is no server, no database, no analytics, and no third party involved.

What the app accesses

The app requests one Google OAuth scope, https://www.googleapis.com/auth/calendar, which lets it read and write events in the signed-in user's own Google Calendar. It uses this solely to create, update and remove calendar events corresponding to tasks in that user's private Plane workspace.

What is stored, and where

Two files are written to the user's own computer and never leave it: an OAuth token file, so the script can run unattended, and a state file recording which task maps to which event, so repeat runs update events instead of duplicating them. Neither is uploaded or transmitted anywhere other than to Google's own APIs during normal operation.

What is shared

Nothing. No data is sold, rented, published or disclosed to any third party. There are no advertisers, trackers, analytics providers or subprocessors. Information obtained through Google APIs is not used to develop, improve or train any generalized or large language model.

Retention and deletion

Data is retained only while the script is in use. Deleting the local token and state files removes everything stored. Access can be revoked at any time at myaccount.google.com/permissions, which immediately ends the app's ability to reach the calendar.

Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
